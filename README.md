# 🔧 OMEGA-Device
## Ultimate ESP32-S3 Multi-tool DIY Security Device

**Open-source firmware** для портативного устройства анализа и управления RF, WiFi, Bluetooth, IR, NFC сигналами.

---

## 📋 Описание

**OMEGA** — это мощный DIY аппарат на базе ESP32-S3 для:
- 🔵 **Bluetooth** сканирования и взлома (BLE)
- 📡 **WiFi** пентестирования (Deauth, Beacon Spam)
- 📻 **Sub-Ghz RF анализа** (CC1101 модуль 433MHz)
- 🔴 **IR контроля** (захват и воспроизведение с линзой 20°)
- 🏷️ **NFC/RFID** чтения карт (PN532)
- 🎯 **2.4GHz RF** анализа (NRF24L01)
- 📍 **GPS** позиционирования (опционально)
- 💾 **Запись данных** на microSD (Samsung PRO Endurance 32GB)

**Всё это в одном портативном устройстве!** 🚀

## 🚀 Быстрый старт

```bash

cd OMEGA-Device
```

- Выбрать режим в меню
- Начать сканирование

## 🔧 GPIO распределение

```
ESP32-S3 GPIO РАСПРЕДЕЛЕНИЕ:

╔════════════════════════════════════════════════╗
║ Интерфейс    │ GPIO  │ Функция               ║
╠════════════════════════════════════════════════╣
║ Дисплей SPI  │ 10    │ CS (Chip Select)      ║
║              │ 9     │ RESET                 ║
║              │ 8     │ DC (Data/Command)     ║
║              │ 11    │ MOSI (Data Out)       ║
║              │ 12    │ SCK (Clock)           ║
║              │ 46    │ LED (подсветка PWM)   ║
╠════════════════════════════════════════════════╣
║ CC1101 SPI   │ 13    │ CS                    ║
║              │ 14    │ GDO0 (Interrupt)      ║
║              │ 15    │ GDO2 (Interrupt)      ║
╠════════════════════════════════════════════════╣
║ NRF24L01 SPI │ 16    │ CS                    ║
║              │ 17    │ CE (Chip Enable)      ║
║              │ 18    │ IRQ (Interrupt)       ║
╠════════════════════════════════════════════════╣
║ PN532 SPI    │ 19    │ CS                    ║
╠════════════════════════════════════════════════╣
║ GPS UART     │ 21    │ TX                    ║
║              │ 20    │ RX                    ║
╠════════════════════════════════════════════════╣
║ microSD SPI  │ 22    │ CS                    ║
╠════════════════════════════════════════════════╣
║ Кнопки       │ 2     │ UP                    ║
║              │ 3     │ DOWN                  ║
║              │ 5     │ LEFT                  ║
║              │ 6     │ RIGHT                 ║
║              │ 7     │ OK                    ║
║              │ 4     │ BACK                  ║
╠════════════════════════════════════════════════╣
║ IR TX (линза)│ 43    │ Output PWM (LED 20°)  ║
║ IR RX        │ 44    │ Input (TSOP4838)      ║
╚════════════════════════════════════════════════╝
```

**Все SPI модули используют общую шину:**
- MOSI: GPIO 11
- MISO: GPIO 13
- SCK: GPIO 12
- CS: разные GPIO для каждого модуля

## 📡 Режимы работы

### 1. **WiFi Deauth Attack**
- Сканирование WiFi сетей
- Перехват beacon фреймов
- Отправка deauth пакетов
- Логирование в SD карту

### 2. **BLE Sniffer**
- Сканирование BLE устройств
- Захват advertising пакетов
- Анализ RSSI (сила сигнала)
- Сохранение MAC адресов

### 3. **Sub-Ghz RF Analyzer** (CC1101)
- Сканирование 300-928MHz
- Real-time спектрограмма
- Захват RF сигналов
- Анализ модуляции (FSK, OOK, etc)

### 4. **IR Control** (линза 20°)
- Захват IR кодов дальнобойной линзой
- Воспроизведение сохранённых команд
- БД популярных пультов
- **Дальность до 100м+ (с линзой 20° угол)**

### 5. **NFC Reader**
- Чтение NFC Type A/B карт
- Сохранение UID и данных
- Эмуляция карт (опционально)
- БД известных NFC

### 6. **2.4GHz RF Analysis** (NRF24L01)
- Сканирование 2.4GHz канала
- Захват RF пакетов
- Анализ различных устройств IoT
- Определение типа радиопротокола

### 7. **GPS Logger**
- Захват координат
- Карта маршрута
- Экспорт в GPX
- Сохранение в microSD

## 📦 Установка и сборка

### Требования
- **PlatformIO** (VS Code)
- **Arduino IDE 2.0+** (альтернатива)
- **USB-C кабель** для загрузки

### Установка зависимостей
```bash
cd Firmware
platformio lib install "TFT_eSPI" "WiFi" "BLE" \
  "SPI" "EEPROM" "SD" "Adafruit PN532" \
  "RadioHead" "TinyGPS++"
```

### Компиляция
```bash
platformio run -e esp32s3
```

### Загрузка в устройство
```bash
platformio run -e esp32s3 --target upload
```

### Мониторинг (отладка)
```bash
platformio device monitor --baud 115200
```
